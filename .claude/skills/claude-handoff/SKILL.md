새 에이전트가 작업을 이어갈 수 있도록 현재 대화의 핸드오프 요약을 작성하라. 저장하는 대신, 그 요약을 프롬프트로 삼는 백그라운드 에이전트를 실행하라: `claude --bg --name "<descriptive name>" "<handoff summary>"`. 현재 작업 디렉터리에서 시작되며 즉시 반환된다. 사용자는 `claude agents`로 이를 관리한다.

항상 설명적인 이름과 함께 `-n`/`--name`을 넘겨라(예: `--name "Fix login bug"`). 작업 목록, 세션 선택기, 터미널 제목에 표시되는 이름을 설정한다.

요약에 "추천 스킬" 섹션을 포함하여, 다음 에이전트가 Skill 도구로 호출해야 할 스킬들을 명시하라.

다른 산출물(스펙, 계획, ADR, 이슈, 커밋, diff)에 이미 담긴 내용은 중복하지 마라. 대신 경로나 URL로 참조하라.

요약이 에이전트의 프롬프트가 되므로 API 키, 비밀번호, 개인 식별 정보 같은 민감한 정보는 모두 삭제하라.

사용자가 인자를 넘겼다면, 그것을 다음 세션이 집중할 내용에 대한 설명으로 보고 요약을 그에 맞게 조정하라.
