# 로그인 없이 공용 비밀번호와 브라우저 쿠키로 접근과 중복 투표를 제어한다

50명 이하 동아리의 가벼운 투표(회식 메뉴, MT 날짜 등)가 주 용도라서 개인 로그인은 두지 않는다. 외부인은 구성원이 공유하는 입장 비밀번호 하나로 막고, 관리자는 운영진이 공유하는 관리자 비밀번호 하나로 구분한다. 1인 1표는 브라우저에 오래 남는 식별 쿠키로만 보장하므로, 시크릿 창이나 다른 기기로 다시 투표하는 것은 의도적으로 막지 않는다.

## 검토한 대안

- **소셜 로그인 / 학교 이메일 인증**: 1인 1표를 확실히 보장하지만, 이 규모와 용도에 비해 구현과 회원 명단 관리가 무겁다.
- **링크만 있으면 누구나 접근**: 가장 단순하지만 링크가 퍼지면 외부인 표가 섞인다.

## 결과와 영향

- 공정성이 중요한 투표(회칙상 선거 등)에는 이 앱을 쓰면 안 된다. 그런 요구가 생기면 이 결정을 다시 검토한다.
- 브라우저 식별 쿠키는 입장 세션과 별개로 오래 유지되어야 한다. 입장 세션이 끝날 때마다 다시 투표할 수 있게 되면 안 되기 때문이다.
- 비밀번호를 바꾸면 기존 입장 세션과 관리자 세션은 모두 무효가 되지만, 브라우저 식별 쿠키는 유지된다.
