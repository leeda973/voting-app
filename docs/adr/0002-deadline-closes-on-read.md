# 마감 시각이 지난 투표는 예약 작업 없이 조회할 때 마감으로 판단한다

투표에 선택적인 마감 시각을 두면서, 마감 시각이 지났을 때 상태를 바꾸는 예약 작업을 두지 않기로 했다. 대신 "관리자가 마감했거나 마감 시각이 지났으면 마감"이라는 규칙을 목록, 상세, 결과 공개, 표 저장 쿼리가 모두 조회할 때 적용한다. 그래서 마감 시각이 지나는 순간 바로 표를 받지 않고, 인프라도 늘지 않는다. 자동으로 마감된 투표의 마감된 시각은 설정했던 마감 시각 값이다.

## 검토한 대안

- **Vercel Cron으로 주기적으로 상태 변경**: Hobby 플랜의 Cron은 하루 한 번만 돌 수 있어 최대 하루 늦게 마감된다. 그 사이의 표를 막으려면 결국 조회할 때의 판단도 필요하다.

## 결과와 영향

- DB의 상태 값만 보고 진행 중이라고 판단하면 안 된다. 마감 여부는 항상 상태 값과 마감 시각을 함께 보는 규칙 하나로 판단한다.
- 마감 시각이 지난 투표에 관리자가 마감 버튼을 누르면 이미 마감된 투표로 처리한다.
