# 분류 라벨

스킬은 표준 분류 역할 다섯 가지로 말한다. 이 파일은 그 역할을 이 저장소의 이슈 트래커에서 실제로 쓰는 라벨 문자열에 연결한다.

| mattpocock/skills의 라벨 | 우리 트래커의 라벨   | 의미                                        |
| ------------------------ | -------------------- | ------------------------------------------- |
| `needs-triage`           | `needs-triage`       | 관리자가 이 이슈를 검토해야 함              |
| `needs-info`             | `needs-info`         | 보고자의 추가 정보를 기다리는 중            |
| `ready-for-agent`        | `ready-for-agent`    | 완전히 정의되어 자리 비운(AFK) 에이전트가 바로 작업 가능 |
| `ready-for-human`        | `ready-for-human`    | 사람이 구현해야 함                          |
| `wontfix`                | `wontfix`            | 처리하지 않음                               |

스킬이 역할을 언급하면(예: "AFK 준비 완료 분류 라벨을 붙여라") 이 표에서 해당하는 라벨 문자열을 쓴다.

실제로 쓰는 어휘에 맞게 오른쪽 열을 고친다.
