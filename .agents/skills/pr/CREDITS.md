# 출처

"변경의 형태(The shape of the change)" 섹션은 [Dex Horthy](https://github.com/dexhorthy)의 [`show-me`](https://github.com/humanlayer/humanlayer) 스킬을 거의 그대로 옮긴 것으로, 실시간 대화 대신 diff를 대상으로 합니다. `pr`은 `show-me`에 스킬로서 의존하지 않으므로(`show-me`는 이 리포지토리에 포함되어 있지 않으며, 강한 의존성은 단독 설치를 깨뜨림) 내용을 가리키는 대신 복사해 넣었습니다. 이 파일은 의존성이 있었다면 담았을 출처 표기를 대신합니다.
