# 트리아지 라벨

스킬은 다섯 가지 표준 트리아지 역할을 기준으로 말한다. 이 파일은 그 역할들을 이 저장소의 이슈 트래커에서 실제로 사용하는 라벨 문자열에 매핑한다.

| mattpocock/skills의 라벨 | 우리 트래커의 라벨   | 의미                                     |
| ------------------------ | -------------------- | ---------------------------------------- |
| `needs-triage`           | `needs-triage`       | 메인테이너가 이 이슈를 평가해야 함       |
| `needs-info`             | `needs-info`         | 보고자의 추가 정보를 기다리는 중         |
| `ready-for-agent`        | `ready-for-agent`    | 완전히 명세됨, AFK 에이전트가 처리 가능  |
| `ready-for-human`        | `ready-for-human`    | 사람의 구현이 필요함                     |
| `wontfix`                | `wontfix`            | 조치하지 않음                            |

스킬이 어떤 역할을 언급하면(예: "apply the AFK-ready triage label"), 이 표에서 해당하는 라벨 문자열을 사용한다.

실제로 사용하는 용어에 맞게 오른쪽 열을 수정한다.
