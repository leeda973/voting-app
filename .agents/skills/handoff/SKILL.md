새로운 에이전트가 작업을 이어갈 수 있도록 현재 대화를 요약한 핸드오프 문서를 작성하세요. 현재 작업 공간이 아니라 사용자 OS의 임시 디렉터리에 저장하세요.

문서에 "추천 스킬(suggested skills)" 섹션을 포함하고, 다음 에이전트가 Skill 도구로 호출해야 할 스킬들을 명시하세요.

다른 산출물(스펙, 계획, ADR, 이슈, 커밋, diff)에 이미 담긴 내용은 중복하지 마세요. 대신 경로나 URL로 참조하세요.

API 키, 비밀번호, 개인 식별 정보 등 민감한 정보는 모두 가리세요.

사용자가 인자를 전달했다면, 이를 다음 세션이 집중할 내용에 대한 설명으로 간주하고 그에 맞게 문서를 조정하세요.
