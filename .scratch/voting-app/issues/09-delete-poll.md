# 09: 투표 삭제

**만들 것:** 관리자가 투표 상세 화면에서 삭제 버튼을 누르면 "복구할 수 없다"는 확인 창이 뜬다. 확인하면 진행 중이든 마감됐든 투표와 선택지, 표가 완전히 사라지고 목록으로 돌아간다. 삭제된 투표의 링크로 들어오면 없는 투표라고 안내되고, 투표 화면을 열어둔 사이 삭제되었다면 표를 남길 때 없어진 투표라는 안내를 받는다.

스펙: [spec.md](../spec.md)의 "데이터 규칙"의 삭제, `DELETE /api/polls/[id]`.

**차단 요인:** 04 (투표 만들기와 투표 상세 보기). 05~08과 병렬로 진행할 수 있다.

**Status:** ready-for-agent

- [x] `DELETE /api/polls/[id]`는 관리자만 쓸 수 있고(아니면 403), 성공하면 204, 없는 투표면 404다
- [x] 삭제하면 선택지와 표가 연쇄 삭제되어 DB에 남지 않는다
- [x] 삭제 버튼은 관리자에게만 보이고, 누르면 "복구할 수 없다"는 문구가 담긴 확인 창이 뜨며, 취소하면 아무 일도 일어나지 않는다
- [x] 확인하면 목록으로 돌아가고, 그 투표가 목록에서 사라져 있다
- [x] 삭제된 투표의 링크로 들어오면 없는 투표라는 안내가 보인다
- [x] 삭제된 투표에 표를 남기려 하면 404와 없어진 투표라는 한국어 안내가 보인다(05가 끝난 뒤라면)
- [x] `npm test`, `npm run lint`, `npm run build`가 통과한다
