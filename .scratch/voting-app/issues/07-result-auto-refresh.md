# 07: 결과 5초 자동 갱신

**만들 것:** 진행 중인 투표의 결과 화면을 열어두면 5초마다 결과를 다시 불러와 숫자가 저절로 바뀐다. 두 기기에서 같은 결과 화면을 열어두고 한쪽에서 표를 남기면 다른 쪽 숫자가 5초 안에 바뀐다. 결과를 볼 수 없는 화면(투표 폼만 있는 화면)에서는 불러오지 않는다.

스펙: [spec.md](../spec.md)의 "화면"의 자동 갱신 규칙, `GET /api/polls/[id]/result`.
