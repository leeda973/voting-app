# 08: 투표 마감

**만들 것:** 관리자가 진행 중인 투표의 상세 화면에서 마감 버튼을 누르면 투표가 마감된다. 마감된 투표는 목록의 마감 섹션으로 옮겨가 최신순으로 보인다. 마감된 투표에는 더 이상 표를 남길 수 없고, 표를 남기지 않은 사람도 결과를 볼 수 있다. 결과 화면을 보고 있던 사람의 자동 갱신은 멈추고 마감 상태가 표시된다. 투표 화면을 열어둔 사이 마감되었다면 표를 남길 때 마감되었다는 안내를 받는다. 마감한 투표는 다시 열 수 없다.

스펙: [spec.md](../spec.md)의 "데이터 규칙"의 마감, `POST /api/polls/[id]/close`, 결과 공개 규칙.

**차단 요인:** 07 (결과 5초 자동 갱신)

**Status:** ready-for-agent

- [x] `POST /api/polls/[id]/close`는 관리자만 쓸 수 있고(아니면 403), 상태를 마감으로 바꾸고 마감 시각을 기록한 뒤 `PollDetail`을 돌려준다
- [x] 이미 마감된 투표를 다시 마감하면 409 `already_closed`, 없는 투표면 404다
- [x] 마감된 투표를 다시 진행 중으로 바꾸는 API나 화면이 없다
- [x] 마감된 투표에 표를 남기면 409 `poll_closed`와 한국어 안내가 돌아오고, 화면에도 그 안내가 보인다
- [x] 마감 요청과 투표 요청이 동시에 와도 마감 이후의 표는 저장되지 않는다(표 저장의 조건부 쿼리로 보장)
- [x] 마감된 투표는 목록의 마감 섹션에 최신순으로 보인다
- [x] 표를 남기지 않은 투표자도 마감된 투표의 결과를 본다
- [x] 결과 화면을 보고 있던 브라우저에서 자동 갱신이 멈추고 마감 상태가 표시된다
- [x] 마감 버튼은 관리자에게만, 진행 중인 투표에서만 보인다
- [x] `npm test`, `npm run lint`, `npm run build`가 통과한다
