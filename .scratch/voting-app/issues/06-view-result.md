# 06: 결과 보기

**만들 것:** 투표자가 표를 남기면 바로 결과 화면이 나온다. 결과 화면은 선택지별 표 수와 비율(%), 총 표 수를 보여주고 내가 고른 선택지를 강조한다. 이미 표를 남긴 투표에 다시 들어와도 결과가 보인다. 표를 남기지 않은 투표자는 진행 중인 투표의 결과를 볼 수 없으며, API로 직접 불러도 403이다. 관리자는 표를 남기지 않아도 결과를 볼 수 있어서, 관리자에게는 투표 폼 아래 결과가 함께 보인다.

TDD로 투표 규칙 모듈의 **결과 공개 여부**와 **결과 집계** 규칙을 먼저 만든다.

스펙: [spec.md](../spec.md)의 "투표 규칙 모듈", "화면"의 투표 상세 규칙, `GET /api/polls/[id]/result`, `PollDetail.canViewResult`.

**차단 요인:** 05 (표 남기기)

**Status:** ready-for-agent

- [x] 결과 공개 여부 규칙이 테스트로 먼저 작성되어 있다: 진행 중에 표 없음(비공개), 진행 중에 표 있음(공개), 마감 후 표 없음(공개), 관리자(공개), 그 조합들
- [x] 결과 집계 규칙이 테스트로 먼저 작성되어 있다: 표 0개(모두 0%), 한 선택지에 몰림(100%), 반올림 경계(3표를 1:1:1로 나눔), 표가 없는 선택지 포함, 선택지 표시 순서 유지
- [x] `GET /api/polls/[id]/result`가 스펙의 `Result` 형태로 응답하고, 볼 수 없으면 403 `result_hidden`, 없는 투표면 404다
- [x] `POST /api/polls/[id]/votes`의 성공 응답도 같은 집계 규칙을 쓴다
- [x] `GET /api/polls/[id]`의 `canViewResult`가 서버의 결과 공개 규칙과 같다
- [x] 결과 화면에 선택지별 표 수와 비율, 총 표 수가 보이고, 내가 고른 선택지가 강조된다(그래프는 없다)
- [x] 관리자는 표를 남기지 않아도 상세 화면에서 투표 폼 아래 결과를 본다
- [x] 표를 남기지 않은 일반 투표자에게는 진행 중인 투표의 결과가 화면에도 API에도 드러나지 않는다
- [x] `npm test`, `npm run lint`, `npm run build`가 통과한다
