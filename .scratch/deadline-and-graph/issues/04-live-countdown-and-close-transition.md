# 04: 화면을 열어 둔 동안 남은 시간 갱신과 마감 전환

**만들 것:** 목록이나 상세 화면을 열어 두면 남은 시간 문구가 1분마다 다시 계산되어 줄어든다. 열어 둔 화면에서 어떤 진행 중 투표의 마감 시각이 되면 화면이 서버에서 다시 그려져 마감 상태로 바뀐다. 목록에서는 그 투표가 마감 섹션으로 옮겨지고, 상세에서는 투표 폼과 관리자 마감 버튼이 사라지고 결과가 공개되며, 결과를 보던 화면은 자동 갱신이 멈추고 최종 결과가 보인다. 카운트다운은 표시일 뿐이며 표를 받을지는 서버가 판단한다.

스펙: [spec.md](../spec.md)의 "화면"의 목록·상세 갱신, 사용자 스토리 25~27, "추가 참고 사항"의 카운트다운.

**차단 요인:** 03 (남은 시간 표시와 마감 임박순 목록)

**Status:** ready-for-agent

- [x] 목록과 상세에서 남은 시간 문구가 1분마다 갱신된다(화면을 떠나면 타이머가 정리된다)
- [x] 투표 폼을 열어 둔 상세 화면이 마감 시각이 되면 1분 안에 마감 상태(폼 없음, 결과 공개, "마감됨")로 바뀐다
- [x] 결과를 보던 상세 화면이 마감 시각이 되면 자동 갱신이 멈추고 최종 결과가 보인다
- [x] 관리자 상세 화면에서 마감 시각이 되면 마감하기 버튼이 사라진다
- [x] 열어 둔 목록에서 마감 시각이 지난 투표가 1분 안에 마감 섹션으로 옮겨진다
- [x] 마감 시각이 없는 투표만 있는 화면에서는 불필요한 다시 그리기가 일어나지 않는다
- [x] 실제 브라우저로 마감 시각이 가까운 투표(DB에 직접 넣어도 됨)를 열어 두고 전환을 확인했다
- [x] `npm test`, `npm run lint`, `npm run build`가 통과한다

## Comments

- 2026-09-25: 구현 완료. 실제 Chrome에서 75초 뒤 마감 투표로 목록·투표 폼·결과·관리자 화면 전환(마감 약 1초 뒤)과 1분 갱신을 확인했다. 마감 시각 없는 화면은 다시 그리기 요청 0회(링크 미리 불러오기만 있음). 기기 시계를 30초 빠르게/느리게 한 경우에도 같은 시점에 전환된다.
