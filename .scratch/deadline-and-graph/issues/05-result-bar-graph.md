# 05: 결과 그래프(가로 막대)

**만들 것:** 결과 화면의 선택지마다 비율만큼의 가로 막대가 생기고, 표 수와 비율 숫자는 그대로 보인다. 막대 길이는 옆의 비율 숫자와 일치한다. 내 표의 막대는 강조색, 나머지는 회색 계열이며 밝은/어두운 테마 모두에서 구분된다. 총 0표면 모든 막대가 빈 트랙으로 보이고 선택지 문구, "0표 0%", "총 0표"가 그대로 보이며 레이아웃이 깨지지 않는다. 5초 자동 갱신 때 막대도 함께 바뀌고, 관리자의 투표 전 결과에도 보인다.

스펙: [spec.md](../spec.md)의 "화면"의 결과 그래프, 사용자 스토리 31~39.

**차단 요인:** 없음(즉시 시작 가능). 01~04와 병렬로 진행할 수 있다.

**Status:** ready-for-agent

- [x] 결과 화면의 각 선택지에 막대가 있고, 너비는 결과 계산 규칙의 비율(%)을 그대로 쓴다(0으로 나누기 없음)
- [x] 바탕 트랙이 항상 보여 0표 선택지는 빈 막대다
- [x] 총 0표인 투표(방금 만든 투표를 관리자가 투표 전에 봄)에서 모든 막대가 빈 트랙이고 "0표 0%", "총 0표"가 보이며 막대 영역 높이가 줄지 않는다
- [x] 내 표 막대만 강조색이고, 밝은/어두운 테마 모두에서 구분된다
- [x] 막대는 보조 기술에 숨겨져 있고(숫자가 같은 정보를 전달), 차트 라이브러리를 쓰지 않는다
- [x] 5초 자동 갱신 때 막대가 함께 바뀐다
- [x] 선택지 10개와 긴 선택지 문구에서도 390px 폭에서 가로 스크롤이 생기지 않는다(실제 브라우저로 확인)
- [x] `npm test`, `npm run lint`, `npm run build`가 통과한다
